# Food Ordering System

A Java-based food ordering system developed using OOP concepts.

## Features
- Customer Management
- Food Item Management
- Order Creation
- Bill Calculation
- Discount Calculation using Abstraction
- Encapsulation and Object-Oriented Design

## OOP Concepts Used
- Class and Objects
- Encapsulation
- Abstraction
- Inheritance
- Polymorphism

## Sample Output
Displays customer details, ordered food items, bill amount, discount and final payable amount.
